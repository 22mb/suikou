# suikou

Claude が日本語の技術文書、規程、報告書、提案書などを執筆・校正する際に読み込むスキルです。

## 特徴

根拠に基づかない内容や誇張表現の追加を禁じ、論理的で締まった日本語を作成するためのルールと手順を定めています。

### 代表的なルールの例

- **条件・時の表現（ルール1）**
  - 悪い例: 設定を変更するときは、バックアップを取得してください。
  - 修正形: 設定を変更する際は、バックアップを取得してください。
- **不要な読点の削除（ルール2）**
  - 悪い例: 切り出したサービスも、原則として Ruby で実装する。
  - 修正形: 切り出すサービスも原則として Ruby で実装する。
- **客観的な文章語への統一（ルール5）**
  - 悪い例: バックグラウンドで定期的にバッチ処理が走る。
  - 修正形: バックグラウンドで定期的にバッチ処理が実行される。
- **比喩・擬人化の直叙化（ルール15）**
  - 悪い例: ここが崩れると、CIは静かに嘘をつき始めます。
  - 修正形: ここが崩れると、CIは静かに誤った判定を下すようになります。

## インストール

```bash
gh skill install 22mb/suikou --scope user
```

## 使い方

日本語の文書を書く・校正する依頼（「日本語で書いて」「校正して」など）を行うと自動的に読み込まれます。校正を依頼すると、校正後の文書の全文だけを返します。

明示的に呼び出すことも可能です。

```text
/suikou
```

## 構成

`skills/suikou/` の2ファイルで構成されています。

- `SKILL.md`
  - **第1部 ルール**: 守るべき制約、基本ルール19個、文脈による使い分け基準（15項目）
  - **第2部 手順**: 執筆の手順、および複数巡走査による校正の手順
- `examples.md`: 基本ルールごとの「悪い例 → 修正形」の実例集。執筆・校正の前に読み込まれます。
