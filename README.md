# suikou

Claude が日本語の技術文書、規程、報告書、提案書などを執筆・校正する際に読み込むスキルです。

## 特徴

根拠に基づかない内容や誇張表現の追加を禁じ、論理的で締まった日本語を作成するためのルールと手順を定めています。

### 代表的なルールの例

- **条件・時の表現（ルール1）**
  - 悪い例: クリックしても、画面が遷移しない。
  - 修正形: クリックした場合でも、画面が遷移しない。
- **不要な読点の削除（ルール2）**
  - 悪い例: 切り出したサービスも、原則として Ruby で実装する。
  - 修正形: 切り出すサービスも原則として Ruby で実装する。
- **客観的な文章語への統一（ルール5）**
  - 悪い例: バックグラウンドで定期的にバッチ処理が走る。
  - 修正形: バックグラウンドで定期的にバッチ処理が実行される。

## インストール

```bash
gh skill install 22mb/suikou --scope user
```

## 使い方

日本語の文書を書く・校正する依頼（「日本語で書いて」「校正して」など）を行うと自動的に読み込まれます。

明示的に呼び出すことも可能です。

```text
/suikou
```

## 構成

`skills/suikou/SKILL.md` の1ファイルで構成されています。

- **第1部 ルール**: 守るべき制約、基本ルール14個、文脈による使い分け基準（15項目）
- **第2部 手順**: 執筆の手順、および複数巡走査による校正の手順
